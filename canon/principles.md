# Principles

Every record in this canon ladders up to one of these.

1. **Reasons over rules.** A standard nobody can explain is a standard nobody
   will keep. Every check traces to a written decision with its context.
2. **Machines check, people decide.** If a rule can be checked mechanically,
   a tool checks it and returns facts. Judgment goes to people and agents.
3. **Secure by default.** Least privilege, pinned dependencies, signed releases
   and minimal runtime images are the starting point, not a hardening pass.
4. **Reproducible or it didn't happen.** Lock files, pinned versions and
   deterministic builds, so the same commit builds the same artifact.
5. **Scripts first, people second.** Tools have plain, structured output for
   automation and add color and prompts only when a person is there.
6. **Tested where it matters.** High coverage as a floor, with benchmarks and
   fuzzing on the paths that parse input or run hot.
7. **Open by default.** Projects are ready to be public: licensed, documented,
   with a way to report vulnerabilities privately.
